# Kaggle dataset publication guide

The v0.1.0 dataset is synthetic and small. It is suitable for a transparent benchmark-data demonstration, not as evidence of real procurement behaviour.

Before publishing:
1. Upload `data/scenarios.jsonl` and `data/labels.jsonl` as separate files.
2. Include `data/SYNTHETIC_DATA_NOTICE.md` and `docs/DATA_DICTIONARY.md`.
3. State clearly that the cases are synthetic and policy labels are benchmark-defined.
4. Include the repository URL only after the GitHub repository has actually been created.
5. Do not title the dataset as real procurement or corruption data.
6. Preserve the MIT software licence and clarify the dataset's synthetic provenance.
